# Callsy

Find opportunities that fit your practice. Prepare your materials once. Apply with greater clarity and less repeated work.

Live app: https://ojaghloum-spec.github.io/Callsy/

This repository hosts the published Callsy web app (index.html) on GitHub Pages. The app uses Supabase's publishable key, which is public by design; private data is protected by row-level security on the server.

To publish an update: Add file > Upload files > drop in the new index.html > Commit changes.
